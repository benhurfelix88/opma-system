# Project Notes

## Workflow

- After applying code changes, always commit and push them to GitHub.
- Push using this command:

  ```powershell
  cd "C:\Users\Administrator\Desktop\opma-system"
  git push
  ```

## Verification

- Lint: `npx.cmd eslint <file>` (no `lint` script in package.json)
- Build: `npm run build` (react-scripts)
- Dev server: `npm start`
